# 玩家使用说明

1. 先安装 64 位 Java 21。
2. 将整个文件夹解压到方便保存的位置，不要在压缩软件内直接运行。
3. 双击“启动器.cmd”。请保留它与 JAR 在同一文件夹，不要只移动快捷入口。
4. 在启动器内添加自己的账号，自行获取并导入 DeceasedCraft 整合包 ZIP。
5. 点击启动。首次启动先下载游戏必要文件，之后检查整合包版本并同步服务器要求的补丁。

这个压缩包不包含整合包、Mod、玩家账号、存档或后台管理密钥。游戏数据在运行后由 HMCL 建立。

默认同步服务：https://sync.decreasedcraftallegiance.com
更新下载：https://github.com/davidOfficial2006/Allegiance-HMCL/releases/latest

当前启动器版本 maint-20261103.3。不是 EXE 版本，Java 21 需要玩家自行安装。

同步配置和受管理 Mod 更新由服务器发布；有启动器本身更新时，请关闭游戏和启动器，再下载新版启动器文件。迁移前保留原来的游戏目录和 .hmcl 数据目录。
