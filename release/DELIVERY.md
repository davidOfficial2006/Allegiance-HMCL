# 启动和调整样式

完整解压整个文件夹，双击 **Allegiance-HMCL.exe**。本包内置启动器所需的 Java 21 和 JavaFX，不需要先安装 Java，也不需要 CMD。

EXE 必须与 app、runtime 文件夹放在一起。不要只把 EXE 拖到桌面；需要桌面入口时，为 EXE 创建快捷方式。

在 HMCL 内添加自己的账号，自行获取并导入整合包。首次启动游戏时，HMCL 仍会按游戏版本准备所需 Java、Forge 和游戏依赖；这与已经随包配好的启动器环境是两回事。

## 调整样式后怎样交接

1. 在这个交付目录运行 EXE，使用启动器自带的外观设置调整背景、主题和配色。
2. 下载的背景、图标等素材建议放入同目录的“样式素材”，再从设置中选择。
3. 修改完成后先退出启动器，让设置写入文件。
4. 告诉我这个文件夹的路径。我会重点对照 `.hmcl/config/launcher-settings.json`、`.hmcl/themes`、`.hmcl/user/themes` 和“样式素材”，把已经保存的样式整理进源码。

“.hmcl”可能是隐藏文件夹。无需把账号、登录信息、整个 .minecraft 或存档上传给我。若修改的是游戏内 FancyMenu，而不是启动器界面，请另行指出具体实例目录。

界面布局等无法通过设置改变的部分，附上截图和修改说明即可。扫描配置不能推断没有保存的操作，也不能直接把修改写进已有 EXE；最终会修改源码，再重新打包。

## 使用范围

本交付包适用于 Windows 10/11 x64，不含 Minecraft 整合包或 Mod。默认读取 `https://sync.decreasedcraftallegiance.com` 的公开同步清单，玩家不需要管理密钥。
